# Borahae Beats 💜
Orquestador de catálogo musical de BTS y solistas para la sincronización inteligente con Spotify.

## Arquitectura
- **Backend (Preproceso):** Node.js para consulta masiva a la API de Spotify.
- **Frontend:** React + Vite + Tailwind CSS con tematización dinámica por integrante/sub-unidad.
- **Base de Datos:** Supabase con control de migraciones por código y políticas de seguridad RLS.
